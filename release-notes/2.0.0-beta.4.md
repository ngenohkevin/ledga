## What's new
- History check offers to move payments that sit on the wrong line, when their balances show which line they belong to.
- On Android 15 and later, if Android blocks SMS access for a Ledga installed from a file, Ledga shows how to allow it.

## Fixes
- Scrolling in a payment's sheet no longer makes it jump up and down.
- Saving a category straight after picking it no longer skips "apply to all".
- Opening another person never shows the previous person's payments for a moment.
- A new line's automatic name never repeats one already in use.
